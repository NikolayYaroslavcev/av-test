# av-test

[Русский](README.md) · **English**

Stack:
- Vue 3
- TypeScript
- Vite
- Tailwind CSS v4
- Pinia

## Description

A responsive interactive component, "Driving test ticket solution player" (Russian traffic rules).

## Features

- navigation 1-20;
- answer selection;
- correct/incorrect;
- favorites;
- images;
- 3D video breakdown / Paywall;
- responsive mobile/desktop.

## Data source

https://github.com/etspring/pdd_russia

`src/data/ticket-1.json` matches the original `Билет 1.json`.

## Commands

```bash
npm install
npm run dev
npm run build
```
